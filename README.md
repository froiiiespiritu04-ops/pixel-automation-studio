# Sunset Automations Studio

Automation Specialist Portfolio — Lovable Prompt

Overall Aesthetic

Retro 16-bit pixel-art portfolio for an Automation Specialist. Warm, cozy, handcrafted feel — not cyberpunk. No neon pink/purple, no glassmorphism. Earthy sunset tones throughout. Headings/body use the Silkscreen pixel font (readable, not decorative-only).
